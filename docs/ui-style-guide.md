# UI 視覺風格指南

最後更新：2026-10-06

## 決定

- 風格方向：**揪飲 JOIN 品牌藍**（2026-10-06，使用者提供 logo 提案，App 改名為「揪飲 JOIN!」（桌面名稱與登入頁；後台網頁標題維持「揪飲 JOIN」），配色照提案的品牌色），取代 2026-09-24 的紫青。分工：品牌藍 `#2563EB`＝按鈕與畫出來的線、深藍 `#172554`＝文字、柔和藍 `#EAF4FF`＝凹槽底、藍 `#1D4ED8`＝連結。**活力橘 `#FF8A00` 與奶茶米 `#FBE7C6` 是 logo 與桌面圖示的品牌色，App 內不拿來當文字或細線**（橘在白底對比僅約 2.4，奶茶米太淺）。
- **桌面圖示已換成設計方提供的版本**（2026-10-07，原稿 [`docs/brand/join-icon-designer.jpg`](brand/join-icon-designer.jpg)）。`mobile/assets/icon.png` 是由它處理的 1024×1024 版：原稿的白色四角與圓角補成同色藍、整張縮到 84% 在四周留安全邊，圓角或圓形由 Android 自己的遮罩決定。登入頁淺色模式用直式主 logo（見「登入插圖」），深色維持線稿；`docs/brand/join-logo-sticker.png`（白邊貼紙版）是之前試過的素材，備用。啟動畫面維持白底（要和狀態列同色，否則 Expo 在打包時警告兩者衝突）。提案建議的圓體字型（思源黑體 Rounded、Poppins Rounded 等）**沒有採用**：需要新增 `expo-font` 與字型檔，違反下一條「不新增套件」，列為未決事項。
- 第一版**不新增任何套件**：只用 React Native 內建元件與系統字型；底部導覽用「圓點＋文字」，小圖形用 View 拼。
- 已套用到**所有畫面**：顧客端、登入選角色與商家端共 19 個路由都使用 `tokens.js` 的設定值；舊樣式已全部移除（2026-09-25）。登入選角色與商家端只換了顏色，版面與按鈕形狀維持原樣，按鈕待重做；商家首頁原本的藍色滿版橫幅改成一般的店名列加柔和藍底統計卡。

數值（色碼、字級、圓角）以 [`mobile/src/theme/tokens.js`](../mobile/src/theme/tokens.js) 與 [`statusTones.js`](../mobile/src/theme/statusTones.js) 為準；[`mobile/tests/themeTokens.test.mjs`](../mobile/tests/themeTokens.test.mjs) 會自動檢查對比度與狀態對照。本文件只說規則與原因。

## 原則

1. **每一種顏色只管一件事。**
2. **全 App 只有 2px 一種線粗。** 實心品牌藍＝可以按；白底加 2px 品牌藍外框＝畫出來的線稿，或「目前被選中」的東西。
3. **整個 App 是平的**：不用陰影、漸層、濾鏡。只有蓋在畫面上方的東西（底部彈窗、提示條）用 Android 原生的浮起效果（elevation）。
4. **中文字只用一般（400）與粗體（700）兩種粗細。** 各家手機的中文字型不同，其他粗細不保證有效；層次靠字級、顏色、留白。
5. **意思不只靠顏色。** 每個狀態標籤都有文字，再加一個小記號：勾＝成功、三點＝進行中、驚嘆號＝留意、叉＝失敗、短橫線＝已結束。
6. **大字要設上限。** 取餐碼、珍珠數字、標籤加 `maxFontSizeMultiplier`（1.1），避免使用者調大系統字體時版面爆掉；固定高度一律改 `minHeight`。

## 顏色

對比度＝兩個顏色看起來差多少。文字要 ≥ 4.5，畫出來的線要 ≥ 3。

| 名稱（設定值名稱） | 色碼 | 用途 | 對比度 |
| --- | --- | --- | --- |
| 白（`page`） | `#FFFFFF` | 頁面與卡片的底 | — |
| 柔和藍（`recess`） | `#EAF4FF` | 凹槽：珍珠盤底板、未選的標籤、頭像、次要面板 | — |
| 深藍（`text`） | `#172554` | 主要文字、實心珍珠、取餐碼面板 | 白底 14.69、柔和藍底 13.21 |
| 石板藍（`textSecondary`） | `#4A5F8A` | 次要文字（只放白底或柔和藍底） | 6.37／5.73 |
| 品牌藍（`accent`） | `#2563EB` | 可以按的實心底（配白字）、2px 畫出來的線 | 白字 5.17；線：白底 5.17、柔和藍底 4.65 |
| 藍（`accentInk`） | `#1D4ED8` | 連結、被選中的標籤文字 | 6.70／6.03 |

## 字級與形狀

- 字級（px，字／行高）：珍珠數字 32／36、取餐碼 52／60、頁面標題 24／32、區塊標題 17／24、價格 18／24、按鈕 16／22、內文 15／23（商家密集畫面 14／20）、標籤 12／16、說明 12／17。
- 圓角：8（標籤內小塊）、14（輸入框）、20（商家卡片）、28（顧客卡片、珍珠盤、取餐面板）、999（按鈕、狀態標籤、珍珠）。按鈕高 52、圓角 26；可點的東西高度至少 44。
- 間距以 4 為單位（4／8／12／16／20／24／32）。顧客畫面左右留 20、卡片內距 20；商家與其他密集畫面左右留 14 到 16、列高 56。

## 招牌元件：當級珍珠盤

- 一顆珍珠＝一杯。實心深藍＝已訂；2px 品牌藍空圈＝還沒人訂的名額。級距很大時一顆代表多杯，旁邊的文字永遠寫精確杯數。
- 只畫「你現在這一級」。下方的級距階梯每級一列：預估用淡紫，結算鎖定後換淡綠。
- 填幾顆的規則（實作時寫成純函式並加測試）：0 杯＝0 顆；達到級距＝全滿；其餘取「無條件捨去、至少 1 顆、最多留 1 個空位」，避免 99／100 杯看起來已經滿了。
- 用在：團購詳情與進度（大盤加階梯）、首頁卡片（迷你 5 顆）、取餐憑證（領幾杯就幾顆）、商家製作清單（杯數圓盤，維持唯讀）。

## 未決事項與已知風險

- 品牌藍配色來自使用者提供的 logo 提案，**沒有經過多方評審**，只做過對比度與色差計算（`themeTokens.test.mjs`）。橘與奶茶米只出現在 logo 與桌面圖示。「進行中」淡藍底與按鈕的品牌藍同屬藍系，靠文字、三點記號與「按鈕是實心」分辨；上實機後要再確認。
- 淡色標籤彼此色差偏小（最小 8.4，例如「失敗」粉紅與「已結束」冷灰），主要靠文字與記號分辨；上實機後要再確認。
- 付款文案是否把「授權」「請款」改成「預留額度」「扣款」：尚未決定，不在本次範圍。
- 導覽圖示：先用「圓點＋文字」。之後若要圖示，需新增套件，或自己畫透明底 PNG（現有兩張品牌 PNG 完全不透明，不能直接染色）。
- 直式主 logo 來源是 1254×1254 的 JPEG，裁切後 709×900 夠用；白邊貼紙版 `join-logo-sticker.png` 只有 443×343 的來源，放大略軟。若要把 logo 用到深色模式，需要設計方提供「反白版」（提案裡有）的高解析檔。
- **顧客端全部畫面目前只在網頁模擬環境驗證過，Android 實機尚未確認。** 模擬用 `react-native-web` 把真正的元件畫成網頁再截圖，看得到排版與顏色，看不到 Android 的實際字型、字距、手勢與無障礙（TalkBack）表現。要在真機確認：取餐碼（52px、有字距）在窄螢幕與調大系統字體時不會爆版、各廠牌中文字型下的行距、導覽列圓點與標籤、即時地圖的圖釘顏色與原生彈出面板、分頁切換的滑動動畫。

## 深色模式

2026-09-25 加入。個人中心右上角有一顆圓形的太陽／月亮鈕（`ThemeToggleButton`），按下去在淺色與深色之間切換；第一次啟動跟隨手機系統的深色設定，切換後會記住選擇（`themePreference.js`）。

- **深色的值**在 `tokens.js` 的 `darkColors`／`darkTones`，鍵名與淺色完全相同：頁面近黑深藍 `#0B1220`、文字淡藍白 `#EAF2FF`、按鈕與畫出來的線改成亮藍 `#60A5FA`（按鈕上的字反過來用深色）、凹槽改成深藍 `#13264A`。取餐碼面板在深色改成淺色面板配深色數字（`onDark` 是數字顏色）。
- **切換是漸變**：新主題的底色圖層先淡入蓋住舊畫面（約 0.18 秒），在圖層底下換掉主題，再淡出（約 0.26 秒），兩段都在原生執行緒。這不是每個顏色各自漸變，因為那要每一格畫面都重新算樣式，手機上會卡。
- **寫法**：畫面與元件不可直接 `import { colors }`。樣式寫成 `const makeStyles = (colors, tones) => StyleSheet.create({...})`，元件裡用 `const styles = useThemedStyles(makeStyles)`；要在程式裡直接用顏色（例如 `ActivityIndicator`）就 `const { colors, tones } = useTheme()`。`radii`／`spacing`／`sizes`／`typeScale` 是不變的，照舊從 `tokens.js` 引用。
- **地圖**：`theme/mapStyles.js` 的 `DARK_MAP_STYLE` 是調成深藍的 Google 夜間樣式，手機版（`customMapStyle`）與網頁版（`styles`）共用，跟著主題切換。地圖上的圖釘用固定顏色，不隨主題變：紅色＝自己的位置、黃色＝有招募中團購的店、青色＝沒有（手機版因 Android 原生圖釘只能指定色相，是近似色；網頁預覽畫同樣的水滴圖釘與店名標籤，兩邊看起來一致）。Google 的商店小圖示在手機版與網頁預覽都已隱藏。選項按鈕（`ChoiceChip`）選中與未選中使用相同字重，只靠外框與底色區分，避免粗體變寬把同一排的按鈕擠得跑位。 **手機版與網頁版必須一致**（網頁版是用來預覽手機版的）：兩邊共用 `mapStyles.js` 的同一組樣式陣列，其中包含「隱藏 Google 商家圖示與名稱」的規則（Android 的 `showsPointsOfInterest` 屬性沒有作用，所以不能靠它）；網頁版不顯示縮放 +／− 按鈕（手機版沒有），手機版關閉旋轉與傾斜（網頁版沒有）。之後改地圖設定時，兩個 `LiveMapScreen` 要一起改。
- **登入插圖**：淺色模式用設計方的直式主 logo `login-logo-light.png`（709×900，去掉白底；原稿 `docs/brand/join-logo-stacked-designer.jpg`），logo 裡已有「揪飲 JOIN」字樣。深色模式維持線稿 `login-hero-dark.png`（淺藍 `#60A5FA`）：logo 的深藍線條在深色頁面上看不清楚，加底板或白邊貼紙都試過、看起來不對（2026-10-06），所以 logo 暫時只用在淺色。舊的 `login-hero-light.png` 已刪除。
- **還沒處理**：App 名稱（「揪飲 JOIN!」）與桌面圖示是原生設定，要重新打包 APK 才會生效（EAS Update 無法更新）；商家端沒有個人中心，目前沒有切換鈕；深色下的畫面只在網頁模擬看過，Android 實機尚未確認。

## 設計預覽

[`docs/ui-style-previews/`](ui-style-previews/) 是選定風格前的比較稿，單一 HTML 檔、直接用瀏覽器開，只是網頁模擬，不是真的 App：

- `direction-A.html`：一筆珍珠（線稿延伸）。`direction-B.html`：杯貼取餐券。`direction-C.html`：奶茶上色，原本的深鈷藍版（這個藍已被否決）。三個是評審後的入圍方向。
- `blue-options.html`：同一個團購詳情畫面套 4 組藍色（深鈷藍、淺藍、霧藍、黑糖褐）。這是 2026-09-20 當時選定的黑糖褐（已於 2026-09-24 改定為紫青，這份預覽只留作決策紀錄）。

這些是決策紀錄，**不隨程式更新**；實際數值以 `tokens.js` 為準。

## 不做的事

- 地圖底圖的「客製樣式」只有深色一種（見「深色模式」）；淺色維持 Google 預設。
- 新增套件，包含數字專用的圓頭字型（需要 `expo-font`）。
- 新功能：商家製作清單「逐杯打勾」、首頁「清單／地圖」切換。這次只換外觀。
- 地圖底圖（Google Maps 的水域、道路等圖磚）維持預設，不做客製樣式檔（2026-09-22 使用者決定）。因此即時地圖那一頁的底圖仍有藍色，這是「App 內不使用藍色」的唯一例外；蓋在地圖上的按鈕、標記、卡片、篩選面板仍照新樣式換。
